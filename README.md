# ✈ Smart Airline Reservation System

A modern AI-powered Airline Reservation System developed using Flask, MySQL, HTML, CSS, JavaScript, and Machine Learning concepts. The project provides a complete flight booking and management experience with smart analytics, secure payment simulation, ticket generation, cancellation system, and admin management dashboard.

# 🧠 Delay Prediction Logic

The project uses intelligent rule-based prediction logic inspired by Machine Learning systems.

Delay prediction is generated using:
- Weather Conditions
- Number of Stops
- Route Conditions

Example:
- Storm / Heavy Rain / Fog → High Delay Chance
- Multiple Stops → Moderate Delay Chance
- Clear Weather & Non-stop Flights → Low Delay Chance

# ⚙ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Smart_Airline_Reservation_System.git
```

---

## 2️⃣ Open Project Folder

```bash
cd Smart_Airline_Reservation_System
```

---

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Configure MySQL Database

Create MySQL database and update database credentials inside:

```python
get_db_connection()
```
